# Threads、IG caption、導流

## 1. Threads：預設是輪播（人的決定，2026-10-12）

**預設：一則輪播貼文＋一則回覆**（spec 寫 `threads.mode: carousel`、不寫 `items`）。2026-10-12 起所有新貼文都用這個；逐張串文（`mode` 省略）是舊做法，只留給已發布的 jev-cascade 與測試。理由：圖多時逐張串文階層太多、操作也複雜。

| 部分 | 內容 |
|---|---|
| 輪播貼文 | 正文 500 字以內，附**全部投影片**（順序同 IG，封面第一張，2～20 張）。**不放連結** |
| 最後一則回覆（置頂） | 帶走的一句話（要有 SkillOpt 這類主角名，單獨被轉貼也看得懂）、文章連結（帶預覽）、同系列其他則的標題 |

**輪播沒有逐張描述，所以正文要自己撐起重點**：
- 開頭放 hook 主標；接著 2～4 段，講核心做法、最重要的一個錨點，並把**被使用主張的限定條件**帶出來（例如前提、只在哪些基準測試上觀察到）；結尾一句說明這是系列第幾則、細節在後面幾則。
- 不要整段重述封面副標；把圖上沒有的切入點或限定條件放進去。
- 白話、段落短，手機上好讀；術語第一次出現要有半句白話（讀者可能不點圖）。
- 引用標記照常（`refs`、`quals`）；正文提到的主張都要列進 `refs`。

最後一則的「同系列」：
- 尚未發布的貼文只寫標題並註明「（尚未發布）」，發布後依回補清單補連結。
- **已發布的同系列貼文**：「同系列：<planned_title>」**單獨一行**，Threads 網址放在**下一行**（不放在同一行，`batch_check.py` 解析「同系列：」那行的標題時，同行有網址會誤判成標題不一致）。連結照完整長度計入字數。**發布前要先把已發布貼文的 Threads 網址補進去**（目前手動，見 `publish-flow.md` §1 第 6 步前）。
- **不使用文字附件**，圖片與 IG 共用同一套。

### 舊做法：逐張串文（legacy）

結構是正文加一串回覆，一次用「新增到串文」發出：正文（500 字內、不放連結、脈絡併入）、每張**內容投影片**對應一則串文（附該張圖加一段描述）、最後一則（帶走、連結、同系列）。封面不單獨成則；內容張一對一成串文；描述不逐字重複圖上的字（程式 A 算重疊率，超過 40% 退回）、必須針對配的那張圖、結尾若提問要問具體的問題。

## 2. IG caption

```
[1] 第一句：主題關鍵字加這則在講什麼（摺疊前）
[2] 逐張摘要：內容張一張一行（有 `label` 小標籤的張，前面自動加小標籤文字，標題已經以同樣的詞開頭就不重複；補充第一個子句超過 24 字就只放主標，不截斷）
[3] 導流行
[4] hashtag
```

| 規則 | 內容 |
|---|---|
| 第一句 | 約 40 字，預設上限 50 字（`caption_first_sentence_max_chars`，待手機預覽後調整）。放讀者會搜尋的詞（例如 RLHF、reward model），**不重複封面主標** |
| 逐張摘要 | `build_package.py` 由**最終的投影片規格**自動產生，格式「・主標（補充第一個子句）」，**不編號**（編號像序號，暗示先後順序，也會因封面與脈絡張不列而從 3 開始）。封面與系列地圖不列。必須在 10 張砍完之後才產生。可開關（`caption_per_slide_summary`），預設開 |
| 導流行 | 見 §3 |
| hashtag | **系列標籤用主題詞，像台灣讀者實際會用的樣子**（例如 `#DSO_LLMJudge`），不要把內部系列 id 或英文詞硬拼在一起（`#DSO_JEVCascade` 被人覺得怪）；用語要跟貼文一致（Judge，不寫判官）。最多 5 個，選小眾精準的，不用 #AI、#科技。系列貼文含一個系列專屬標籤（例如 `#DSO_Jev`，必須在 `hashtags` 裡）。獨立 post 沒有系列標籤 |

## 3. 導流與系列導航

**貼文結尾只有兩個去處：**
- **主要**：系列的其他則（站內）。
- **次要**：一個外部連結，指向 blog 文章。**不提 podcast，不要求追蹤。**

| 平台 | 做法 |
|---|---|
| IG | 貼文內的連結不能點。導流行預設寫**文章標題**（`caption_nav_line_mode: article_title`，標題取卡的 `sources[].article_title`），確認 blog 搜尋可用後可改成**搜尋關鍵字**（`search_term`）。個人簡介連結固定指向 blog 首頁 |
| IG 系列導航 | 靠封面的系列色帶與系列名稱、系列 hashtag（精選集與置頂不做） |
| IG 限時動態 | 不做（連結貼紙 API 不支援，人也不手動做） |
| Threads | 連結放最後一則串文，不放正文 |

**不使用「留言關鍵字換連結」**：容易被判定為互動誘餌。

> 卡有 `article_title` 欄位，導流行用文章標題，不要用文章 slug 或自己簡寫的關鍵字。

## 4. 口吻

- 貼文直接以論文或官方為來源，不說「我的文章寫過」。導流行是唯一例外。
- 不提 podcast（podcast 連結放個人檔案）、不加 AI 揭露。
- 語言：目前只做繁體中文（`lang: zh-TW`）。
- 中文 AI 腔黑名單由程式 A 檢查（`params.yaml` 的 `ai_tone_blacklist`，初稿，待人確認）；編輯審查者也會抓。

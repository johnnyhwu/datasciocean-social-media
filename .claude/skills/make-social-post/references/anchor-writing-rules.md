# 錨點類型的寫法規則

每條主張在卡上有 `anchor_type`（定義在 `concept-wiki/docs/card-format.md` §6）。貼文用這條主張時，**寫法由類型決定**；忠實者逐區塊檢查，程式 A 對「部落格判斷」做提示。

**新增錨點類型時，必須同時在這裡定義寫法**（兩個 repo 的契約，見 concept-wiki 的 CLAUDE.md）。

| 類型 | 寫法規則 |
|---|---|
| 實驗結果 | 可直述，但要有比較對象與適用範圍 |
| 設計參數 | 主詞必須是方法名（「X 的做法是…」），不得用「最佳」「應該」 |
| 官方宣稱 | 主詞必須是宣稱方（「官網宣稱…」「官方的做法是…」） |
| 第三方實測 | 標明測試方與比較對象 |
| 數學推導 | 可直述，附數字與前提假設 |
| 外部研究引用 | 寫成「某研究顯示…」，語氣保守 |
| 原作者解讀 | 必須標「作者認為」 |
| 部落格推論 | 必須標「我的推論」 |
| 部落格考證 | 標明是換算或解讀，附算式或前提（例如「依我的整理」） |
| 部落格判斷 | 可以直接以作者的口吻寫，**不必標「我的判斷」**（人的決定，2026-10-08：讀者本來就把整則貼文當成作者的產出）；但不得寫成卡上沒有的普遍事實、不得比卡上的句子更強，卡上的限定條件照樣帶出 |
| 背景說明 | 直述，不當成本文的發現，不加「我的」 |
| 部落格舉例 | 必須標明是假設的例子，不寫成實際發生的事 |
| 社群評論 | 寫成「某社群最高票留言指出…」，不當成事實，不當成權威結論 |

## 通用規則

- 數字要有比較對象：「25 倍」不行，要寫「Every 實測對比 Fable 5.1 快 25 倍」。圖表上的單位與比較對象也要寫明（只寫「倍」沒說是速度要判錯）。
- 卡上沒有的比較詞、全稱詞不能出現（更、最、都、全、幾乎、常常、總是、從不、沒贏、遠不如、大幅、完全、一定，程式 A 檢查）。
- 限定條件跟著主張走：用了主張就要帶出它的 `qualifiers`（用 `quals` 標記）。
- `author_confirmed` 的主張寫法取保守，不得比卡上的句子更強。

## 第一人稱的「我的判斷」

**2026-10-08 人決定：不必再標「我的判斷」**（圖與文字都不用）。貼文口吻直接以論文或官方為來源，卡上的部落格判斷用作者的口吻直述即可，不說「我的文章寫過」。仍要守的：不加卡上沒有的判斷、不比卡上的句子更強、限定條件帶出。「部落格推論」仍標「我的推論」、「原作者解讀」仍標「作者認為」（它們不是作者本人的定論）。以前的貼文（`jev-cascade-overview`）已發布，維持原樣。

## 部落格判斷與官方宣稱混在同一句時

拆成兩個區塊或兩個句子：官方宣稱的部分以官方為主詞，部落格判斷的部分以作者的口吻另寫一句。不要用一個無主詞的句子同時承載兩種來源。

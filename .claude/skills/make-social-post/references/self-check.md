# 派審查之前的自檢清單

忠實者的 blocker 幾乎都是撰寫者自己能先抓到的，每多一輪約 5～6 萬 token，所以**程式 A、B 都過、`build_package.py` 跑完之後，先照這份逐項看過 `post-with-refs.md` 與縮圖，再派審查者**。每項後面的日期是人或審查者抓到它的時間；新類型出現就加在對應的組，過時的就刪。

## 寫 spec 之前（規劃時就要做，不要等渲染後）

- **版型規劃**（`ig-carousel.md` §0）：每張選好版型，下半部放什麼；同圖型不連續 3 張以上（優先選 `brand-and-layouts.md` §4.2 有畫面感的）。
- **圖要比文字多給資訊**（2026-10-15、10-18 兩次）：每張圖寫一句「圖拿掉，讀者少了什麼」。圖上的字和補充說同一件事、只是裝進框裡，就換成具體的假設例子（帶數字、自己重算過、圖註標「假設的例子」）、關係、流向或對比。**卡上沒有材料可補的圖或頁，預設合併或刪掉，不留「只重述主標」的頁**（2026-10-23：Bradley-Terry 的推導頁圖只重述主標，仍放行了；要保留由人拍板）。程式 A 對重疊過高提 HINT。
- **概念依賴表**（2026-10-23：Bradley-Terry 人的十幾條回饋大多是「概念階梯少一階」，審查者沒抓乾淨）：機制或數學類貼文，先列一張表：每個術語、符號**第一次出現在哪一張、在哪一張用白話定義**；每個推導步驟的前置是什麼、前面有沒有鋪墊；某個假設為什麼成立。符號類特別要寫清楚「括號裡放的是什麼」（例：σ 裡放 r 的差，不是 p 的差）。缺的那一階補在前一張，或加一張銜接頁。
- **圖上術語都要在同一張或更早的張定義**，**只在 Threads 定義不算**（只看輪播的人看不到）。背景詞清單內的詞除外。專有名詞、題庫名稱也是；定義只描述卡上說的事、不加用途（卡沒說「這是題庫」，就寫「兩組不同的題目」；Judge 這類背景名詞可用通用白話）。
- **評價類的張**：卡上沒有具體內容可畫的，合併或不放（`ig-carousel.md` §1）；連三張評價、或得自己發明例子才撐得起的，刪。
- **論文書目資訊**：貼文提到論文，預設補作者與年份；卡上沒有的外部查證規則見 `anchor-writing-rules.md`。
- **獨立貼文的去處**：轉折張、延伸閱讀、導流連結、Threads 回覆**打包成一個問題問人**，每個選項附發出去的樣子（`spec-json.md`「獨立貼文」）。

- **有用卡上的圖時**（2026-10-24 契約，`anchor-writing-rules.md`「參考圖」）：選主張時，附圖的主張要**用 Read 看圖**，再決定要不要重製、重製哪一部分。重製圖上的每個數字與關係都要出自**這張引用的主張**，不是圖上其他格子；原圖標明的範圍（資料集、模型組、圖例）不能因為取捨而消失；圖看不懂或太複雜就不用。`fig_refs` 要填，審查材料才有原圖。

## 內容與忠實度

1. **每個數字的比較對象**：圖、標題、補充、Threads、**caption 逐張摘要**、串文，每個數字旁邊都寫得出「跟誰比」。caption 摘要是標題加補充第一個子句自動組成，標題裡的「27%」沒寫是誰的，caption 那行就缺比較對象。
2. **範圍詞對得上卡**：「較難」「全新」「所有」之類，回卡上找這個詞標在誰身上。
3. **封面**：主標加副標合起來看每句字面為真；範圍由副標限定；不暗示卡上沒有的範圍（`hooks.md`）。副標也要白話：給數字就附單位與比較對象，避免「差距」「點」這類內部詞。
4. **形容詞、程度詞與卡上的限定詞逐個對照**：卡寫「略勝」就不能寫「大幅」、寫「量的是不同的東西」不能升級成「互相獨立」；往往、大致、可能、通常、「才」（卡寫「超過就會」不能寫成「才需要」；反過來卡寫「共用實體的事件才會串起來」，也不能寫成「只要共用實體就串起來」，充分與必要不能互換）、唯一（常只針對某個對象）、「看不到」指哪一份資料。指標用詞也要精確：Recall@5 是找回的比例，不寫「前 5 筆變多」（會被讀成筆數）。語氣詞（居然、竟）可以。
5. **每條用到的主張的限定條件**：`quals` 標記的區塊，文字真的把那條限定寫出來了嗎？（只標 `quals` 不寫內容，忠實者會判掉。）主標的絕對詞（「不會」「一定」「只會」）要把卡上「失敗時」「選對時」「在這個任務上」這類條件寫進去。
6. **名詞與範圍的歧義**：只看標題的人會不會誤會？「不要用」是不要用整個方法，還是只在某種情況下？範圍要寫進標題。
7. **串文描述**：不是重述圖；內容針對配的那張圖；別張圖才有的資訊搬到對的那則。
8. **比喻的分界要和卡一致**：例：「改考卷、標準答案在旁邊」≠ 卡的「答案能直接讀出」；「沒有證據可對照」是獨立的第三類，不是第二類的延伸。
9. **機制白話的尺度**（人的決定，2026-10-12）：可以用白話解釋，只要不改變意思、不加新事實（新的原因、用途、數字、範圍）。問自己：這句白話拿掉後卡的意思有沒有變？有沒有出現卡上沒有的因果？
10. **機制類的張，白話夠不夠**（2026-10-15）：要回答「做什麼、怎麼做、為什麼這樣做」；補充寫到字數上限就停通常是不夠的徵兆。讀者看完能不能用自己的話向朋友講一遍？講不出來就補，補不下就拆張或砍次要證據。
11. **統計與實驗術語白話化**：「誤差範圍」「區間不含 0」「留作驗收」「推理強度」「選擇集」換成一般人看得懂的話且不改變卡的意思，換不出來就刪；以沒有 AI 背景的人為讀者（2026-10-10）。否定句與圖框裡的術語（「不做 bootstrapping」）同一張要有「它是什麼、為什麼要在意」一句話（2026-10-18）。
12. **並列的條件要標號**：同一句並列 3 個以上的條件、步驟或限制，用「第一、第二、第三」或圖上的編號圓點分開。
13. **用語一致、不交代資料缺口**：整則（含圖上、Threads、caption）用語一致（資料集三個名稱、目標 Agent、教練）；跑過 `config/terms.yaml`（程式 A 擋）；不寫「文章沒有提到／卡上沒有」。
13b. **說明用的例子**（2026-10-25 sag：換成 TSMC 例子時，忠實者擋了兩次）：例子要演出卡上的機制本身。例如「跳板跟問題字面不像」，例句就不能和問題共用關鍵字（問題問「博士學位」、跳板也寫「博士學位」，等於例子推翻了主張）。真實公司或人物可以當例子，圖上註明「例子」與哪些部分是假設；例子不得被讀成實驗結果（資料集、數字另標來源）。
14. **雙卡貼文的引用標記**：句子內容來自哪張卡，`refs` 就標那張卡的主張（帶 `卡id:` 前綴）；兩張卡有相同的背景主張時，用到的那條要標對卡，限定條件也要標。
15. **前向指稱**：細節在別處時寫「此系列的後續 post」，不寫「後面」（程式 A 擋）。

## 渲染後（自己看圖）

16. **每張圖的下半部**：有沒有空的海面或大片空白？有就換成表或圖，或補內容。
17. **圖有沒有直接支撐主標**（`chart-thinking`）：主標說的事，圖上看得到嗎？（反例：主標寫「不會掉分」，圖只畫費用。）只看圖與主標能不能講出結論？**示意圖的形狀也是主張**：箭頭、跳數、長短若暗示卡上沒有的結果（例：畫 SAG 一個箭頭就到答案，卡只說擴展設為 1 跳），改標籤或加圖註說明「示意」。
18. **排版**：數字與單位有沒有被拆行（程式 B 會擋）、中英混排的詞有沒有被拆開、短條圖的標籤有沒有擠在一起；`label`（「第一關」）與標題開頭不要重複。
19. **圖上格子的連續字數**：`word-break: keep-all` 下連續無標點的中文超過格子寬就溢出；寫 spec 時照 `ig-carousel.md` §4「圖上格子的連續字數」先斷句或縮短。
20. **圖與表放得下嗎**：補充超過 3 行的表或圖，下面常放不下（程式 B 擋「不超出下緣」）；先縮短補充，不縮字級；需要更多白話解釋又沒位置時，先砍評價或次要證據（`ig-carousel.md` §5）。
21. **置中與對齊**（2026-10-15）：程式 B 量不重疊與不超出，不量視覺平衡。看內容塊在可用區域內是否上下均衡、icon 與文字是否對齊中線。
22. **含 LaTeX 的頁**：算式有沒有被框切到、分數與上下標有沒有擠在一起；公式的每個符號在同一張或更早的張講過。

## 組好發布文字之後

23. **caption 逐張摘要**：看自動組出來的幾行：有沒有斷句、重複主標、判斷句被直述成事實。
24. **新欄位有沒有輸出**：改版型或加了 spec 欄位時，確認 `post-with-refs.md`、`ig/post.md` 都看得到那段文字。含 LaTeX 的貼文，`build_package.py` 會擋殘留的 `$`。
25. **改完 spec 要完整重跑**：程式 A → 程式 B → `contact_sheet.py` → `build_package.py`，再看一次縮圖；只重跑一部分，caption 與審查用文字會是舊的。
26. **讀者與編輯的「易懂」「圖」建議預設採用**（見 `review-loop.md`）。

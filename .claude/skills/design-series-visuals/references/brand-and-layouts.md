# 品牌常數、版型、選圖與測深圖

所有 IG 圖片（含 Threads 附圖，兩邊共用同一套）的設計與渲染規則。渲染與程式 B 檢查在 `make-social-post` skill（`references/program-b.md`）。

## 1. 基本規格

| 項目 | 規格 |
|---|---|
| 畫布 | 1080 × 1350 像素（4:5 直式），所有張數比例必須一致 |
| 左右邊界 | 文字與關鍵元素距離左右邊緣至少 40px。個人頁面的格狀縮圖以 3:4 顯示，**左右各被裁約 34px**（上下不裁）。此數字來自討論時的資料，待手機實機確認 |
| 文字內距 | 預設左右各 80px |
| 圖片製作 | 只用程式產生（HTML 模板加無頭瀏覽器截圖）。**數據圖與文字圖一律不用 AI 生圖**（文字常出錯，數字可能畫錯） |
| 內容與外觀分開 | LLM 只產出內容規格 JSON（`make-social-post/references/spec-json.md`）；外觀完全由模板決定 |
| 重製，不用原圖 | 論文或文章的原圖一律根據數字重畫。例外：圖本身就是證據（例如模型的實際輸出），授權允許，且能裁切到手機看得清楚時，可裁切原圖並標明出處 |

## 2. 品牌哲學與常數

**品牌哲學：深處的光。** 取自 podcast 封面（`assets/brand/image.png`）：鉛錘垂進一層層漸深的海，在最深處發出金光。深處是證據所在的地方，光是被挖到的洞見。畫面以米色紙面為底，以海浪的深淺為層次，金色只留給最重要的那一個元素。

| 常數 | 值 |
|---|---|
| 米色（底色） | `#F2E0C0` |
| Logo 藍綠（主標） | `#076876` |
| 深海（補充文字、深色底） | `#01353F` |
| 金色（強調，只給一個元素） | `#DDA642` |
| 淺藍綠、中藍綠、最深海 | `#69B4AA`、`#1F8A8D`、`#032027`（海浪色帶、面板、漸層；成對橫條圖的第一個量用中藍綠、第二個量用深海） |
| 字型 | Noto Sans CJK TC（開源授權），**內嵌在專案裡**（`assets/fonts/`），不依賴系統字型。字重只用 400 與 700，不用細字 |
| 字級 | 允許集合 {28, 34, 38, 40, 56, 72, 76}：主標 72～76，補充 38～40，標籤名 34，副標籤 28，數字 56（成對橫條圖的數字 40）；**下限 28px**。程式 B 檢查所有字級都在集合內 |
| 固定標記 | `@datasciocean`（角落） |

**對比度規則**（WCAG，一般文字至少 4.5）

| 文字色 | 底色 | 對比度 | 結論 |
|---|---|---|---|
| 深海 | 米色 | 10.2 | 補充文字 |
| 藍綠 | 米色 | 5.0 | 主標 |
| 米色 | 深海 | 10.2 | 深色面板上的文字 |
| 金色 | 深海 | 6.1 | 可用 |
| **金色** | **米色** | **1.7** | **禁止用於文字**，只能當色塊、底線、圖形 |
| 中藍綠 | 米色 | 3.2 | 只適合大字或圖形 |

米色底上要強調關鍵字，用金色螢光筆式的底色塊（`[[關鍵字]]` 標記），字維持深海色。

## 3. 版型（八種；`chart_bars` 另有成對橫條圖的變形）

| 版型 | 用在哪 | 底色與重點 |
|---|---|---|
| `cover` 封面 | 第 1 張 | 米色底；主標在畫面中段、副標在下；下段一條**海浪色帶**，顏色依系列，帶上放系列名稱；關鍵字用金色螢光筆標記；紋理只用在封面與帶走張 |
| `context` 脈絡 | 第 2 張 | 米色底；補充 140 字內，可加名詞對照表（`rows`，約 3 個詞放得下），圖上會出現的專有名詞在這一張或更早的張定義 |
| `text` 文字內容 | 機制、限制、評價等 | 米色底；主標在上、補充在下，位置每張固定；下方有一條鉛錘繩（裝飾，class `deco`） |
| `table` 對照表 | 兩欄對照（最多 4 列） | 米色底；主標在上，補充最多 2 行（`.body.sm`），列高依文字斷行估算；右上角可有小標籤 `.chip`（金色細框）；補充可到約 4 行，表與圖依補充行數自動往下讓位；鍵欄寬可用 `key_w` 調，鍵可寫「主｜小字」；4 列以內 |
| `chart_bars` 橫條圖 | 錨點、證據 | 米色底，軸從 0 起，條長與數值成正比。**成對橫條圖**（`value2`）：同一批對象的兩個量（同單位）共用同一個 0 起點與比例尺，每組兩條，圖例在圖上方、名稱下可有一行小字；不用雙軸（2026-10-10 加入） |
| `chart_sounding` 測深圖 | 錨點、證據（Jev 系列的實作） | **深色海面面板**，見 §5 |
| `takeaway` 帶走 | 倒數第二張 | 深海底，金色字，只有一句話，字最大，適合截圖 |
| `series_map` 系列地圖（獨立 post 為「延伸閱讀」） | 最後一張 | 米色底；列出同系列各則標題，目前這則用深海色塊加金色標記；底部導流行 |

**系列標籤**：同一系列每則貼文的每一張，都要有系列標籤（封面放在海浪色帶上，其餘放左上角），文字必須與系列檔的 `name` 完全相同。獨立 post 沒有系列標籤。

**系列色**：從四層海浪深淺中選，相鄰系列不同色。獨立 post 用一個專屬色，不放系列名稱。

**主標位置**在所有版型（封面除外）都固定在同一處，讓讀者滑動時視線不用重找。

## 4. 依內容特徵選圖

| 內容特徵 | 圖的類型 | 元素上限 |
|---|---|---|
| 幾個數字的大小比較 | 橫條圖或測深圖，軸從 0 起 | 3 條 |
| 同一批對象的兩個量一起看（同單位） | 成對橫條圖（`chart_bars` 加 `value2`） | 4 組 |
| 一個量被拆成幾部分（例如 75 題 = 60 題補得回 + 15 題補不回） | 堆疊橫條（尚未實作；目前用三條橫條加名稱寫「其中」） | 3 段 |
| 隨某個變數的變化趨勢 | 簡化折線圖（尚未實作） | 3 條線 |
| 步驟或流程 | 由上往下的箭頭流程（4:5 的垂直空間比水平多；**尚未實作，優先做**，見 `principles.md` 八） | 5 步 |
| A 與 B 的對比 | 左右對照 | 2 欄 |
| 兩個領域的對應關係 | 兩欄對照表 | 3 列 |
| 分情況判斷 | 簡單決策樹（尚未實作） | 2 層 |
| 真實的模型輸出 | 裁切的原圖（授權允許時） | 1 張 |

共通規則：一張圖只傳達一個訊息；**圖要直接支撐主標**（`chart-thinking`）；**直接標示，不用圖例**（成對橫條圖是例外：兩個量共用名稱時，圖例貼在圖上方）；數字直接標在圖上並寫明比較對象；強調色只給一個元素；軸從 0 起，不截斷（若非截斷不可，要明確標示）。初期**不做比喻插圖**，只做可以用程式產生的圖。不是每張都需要圖，說明為主的投影片用純文字版型。

要用「尚未實作」的圖型時，先在 `render.py` 與模板加上該版型、補程式 B 的檢查，**由人審過樣張**，再用。

## 5. 測深圖（`chart_sounding`，Jev 系列的實作，可當範例）

LLM 只輸出宣告式規格，模板負責所有計算：

```json
{ "layout": "chart_sounding", "unit": "倍",
  "bars": [ {"name": "官網頭條", "subs": ["最佳案例", "對比前沿模型"], "value": 193.6, "emphasize": true},
            {"name": "Every 實測", "subs": ["對比 Fable 5.1"], "value": 25} ] }
```

| 元素 | 規則 |
|---|---|
| 水面線 | 唯一的零點，所有繩子從它垂下 |
| 繩長 | 與數值嚴格成正比，由程式計算 |
| 鉛錘 | 小菱形，中心落在繩端 |
| 強調 | 只有一組（繩加鉛錘，金色，並有淡淡的光暈）；其餘用米色 |
| 刻度 | 在左右兩側邊緣，等距，每四格加長；**單位由程式依最大值挑選**（使相鄰刻度間距約 40～120px），圖例（「刻度每格 N 倍」）由程式產生 |
| 標籤 | 名稱與比較對象對齊繩的起點；數字貼在鉛錘右側；**數值很小的標籤改放水面線下方**，不得壓在線上 |
| 小數值 | 軸從 0 起，小值的繩可能只有十幾像素，這是誠實的視覺，不修，標籤放外側 |

不用深色面板的場合，改用 `chart_bars` 的米色底橫條圖。

## 6. 未驗證事項

- 手機實機顯示（只在 1080 寬的畫面檢查過）、格狀縮圖左右各裁 34px 這個數字
- 深色面板與米色底的版型之間，滑動時的視覺節奏（人看過樣張並同意；實測貼文數量還少）

# 視窗（Window）

**一個視窗，裡面一行一行往下長；游標永遠停在最新的一行。**

## 空間與形式

米色紙面上放著一個深色的視窗：細窄的標題列、三顆淡淡的點、下面一行一行的紀錄。視窗不是主角，是舞台；它永遠比文字小一階，只出現在文字下面或封面的下半，從邊緣探出來，不把畫面關起來。封面的視窗歪三度、從右下角探出；內頁的視窗端正、放在文字下方，像一件被放在桌上的工具。

## 色彩與材質

米色是桌面，深海是視窗，視窗裡的字是米色與淺藍綠，細小的字用米色壓低透明度。金色只給游標，一個方塊，永遠只有一個。沒有漸層，沒有陰影，沒有光暈；視窗是平的，像螢幕本身。

## 尺度與節奏

視窗的字比正文的字小，但不小於 28 像素；一行一行的間距固定。同一則裡，越後面的一張，游標停得越往下一行。內頁右下角一排小點，點數是這則的張數，現在這張是金色。

## 構圖與層次

文字永遠在最上層，視窗與游標在最底層。封面：標題與副標在上、視窗在下、視窗歪斜；內頁：標題與補充在上、視窗或圖在下。深色的帶走張把視窗縮成一個輪廓，只留一行提示符號與游標。

## 工藝

每一行的位置、游標的位置都由固定規則算出，不憑感覺擺放；每一張只改變游標停在哪一行。完成後的修正只做減法：拿掉任何不是在說「一行一行、做完一件再做下一件」的東西。

## 貼文正文（附下方全部圖片）

```text
Skill 怎麼調才有效？讓 AI 照紀律自己調！

SkillOpt 把深度學習訓練的紀律帶進 Agent Skill 的優化：看一批紀錄、限量修改、用沒看過的題目驗收。跟 TextGrad、GEPA 這類基準方法比，52 組測試每一組都是最佳或並列最佳。

做法是讓一個通常能力更強的前沿模型當教練，讀目標 Agent 的執行紀錄，提出怎麼改 Skill；目標 Agent 的模型權重凍結不動。

先說明前提：整套設計靠便宜、可靠、自動化的評分方式；創意寫作、開放式客服對話這類主觀任務，評分可能得靠 LLM-as-judge，成本與雜訊又會回來。

這是系列第 1 則，每條紀律的細節，後面幾則會再細講。
```

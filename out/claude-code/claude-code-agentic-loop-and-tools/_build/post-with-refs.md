讓 Claude Code 自己改檔案、下指令，不會出事嗎？

它的核心只有一個迴圈：呼叫工具、觀察結果、自己決定下一步，一直做到它判斷任務完成。測試失敗了？錯誤訊息會直接變成下一輪的輸入，它看著錯誤自己修。

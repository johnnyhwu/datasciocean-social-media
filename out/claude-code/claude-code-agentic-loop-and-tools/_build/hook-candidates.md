## 並列式

## 反差式
C1. 主標：Claude Code 沒有規劃模組，卻能自己改程式
    副標：規劃和執行都在同一個迴圈裡；它看著剛發生的結果，再決定下一步。

    副標：它只求一件事：犯錯的代價要低廉，而且改得回來。
